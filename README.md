# Python GUI and Basic Scripts

This repository contains small Python exercises created for a school subject focused on Python programming, especially beginner-level GUI and scripting tasks.

The goal of this project is to practice:
- Python basics
- Input and output operations
- Conditional logic
- Simple problem-solving
- GUI development with Python
- Writing clean and readable code

## Project Overview

This repository includes simple programs that help students learn how Python works in practice. Some examples focus on command-line scripts, while the project is also oriented toward graphical user interface (GUI) development using Python.

## Repository Structure

```text
Python-GUI/
├── .venv/                  # Virtual environment for the project
├── Upr1/                   # Exercise folder
│   └── is_leap_year.py     # Script to check if a year is a leap year
├── hello_world.py          # Simple introductory Python script
├── .gitignore              # Git ignored files
├── README.md               # Project documentation
└── ...
```

## Included Scripts

### 1. hello_world.py
A basic Python script that prints a greeting to the console.

### 2. Upr1/is_leap_year.py
A small exercise that asks the user for a year and decides whether it is a leap year.

## Requirements

Before running the scripts, make sure Python is installed on your computer.

You can check with:

```bash
python --version
```

## Setting Up the Virtual Environment

It is recommended to create a virtual environment for this project.

### Create a venv

```bash
python -m venv .venv
```

### Activate it

On Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

On Windows Command Prompt:

```cmd
.venv\Scripts\activate.bat
```

## Running the Scripts

### Run the hello script

```bash
python hello_world.py
```

### Run the leap year script

```bash
python Upr1/is_leap_year.py
```
